# Source Code

The project implementation was developed using Jupyter/Google Colab
notebooks.

The notebooks contain the Python and PySpark code used for data
loading, cleaning, standardisation, processing, and analysis.

No standalone Python (`.py`) source files were used for this project.
The notebooks are therefore provided in the `notebooks/` directory as
the main implementation files.

The raw Parquet data used during development was stored separately in
Google Drive and is not included in this directory or in the GitHub
repository due to its large size.
